# Different Vision - Посмотри на мир другими глазами
<img src="Frame 1.png"></img>
**Different Vision** — интерактивное веб-приложение, которое позволяет увидеть привычные изображения по-другому, моделируя различные особенности зрительного восприятия.
Проект создан для знакомства с особенностями цветового зрения, изучения визуальной доступности и проверки цветовых решений в дизайне.

## Возможности
* Протанопия - симуляция особенностей восприятия красного цвета.
* Дейтеранопия - симуляция особенностей восприятия зеленого цвета.
* Тританопия - симуляция особенностей восприятия красного цвета.
* Оттенки серого - преобразование цветного изображения в черно-белое.
* Размытие - имитация нечеткого зрения.

*Каждый эффект можно настроить отдельно и комбинировать несколько одновременно*

## Как пользоваться
1. Откройте веб-приложение.
2. Загрузите изображение с устройства.
3. Выберите нужные визуальные эффекты.
4. Настройте интенсивность каждого эффекта с помощью ползунков.
5. Нажмите «Скачать результат», чтобы сохранить обработанное изображение.

> [!WARNING]
> **Важно**: этот инструмент создан для обучения и повышения осведомлённости о доступности. Он не диагностирует нарушения зрения и не заменяет консультацию специалиста. Реальное восприятие у разных людей может отличаться.
